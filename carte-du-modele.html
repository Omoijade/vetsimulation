Modifier le jeu en 5 étapes

Le plus simple : dans le jeu. Paramétrage › Atelier de l’enseignant, avec le code de l’atelier : un éditeur plein écran pour les règles, les prix et prix acceptés, les salaires, les salles et l’équipement, le fonctionnement, la clinique de départ, la monnaie et les noms (français et anglais). L’effet sur votre clinique est affiché avant d’appliquer, et un fichier de règles peut être donné aux étudiants. Les réglages offerts dans l’atelier sont marqués « atelier » dans la liste ci-dessous.

Pour tout le reste, les nombres sont dans un seul fichier, data.js :

  1. Ouvrez le fichier data.js dans un éditeur de texte.
  2. Cherchez le nom du réglage (Cmd+F ou Ctrl+F) — les noms sont donnés sur cette page, par exemple refusedLeave.
  3. Changez le nombre, rien d’autre. Gardez le point comme séparateur décimal (.08, pas 0,08) et la virgule à la fin de la ligne.
  4. Lancez une seule commande dans le terminal, depuis le dossier du jeu : node outils/verifier-tout.js
  5. Lisez le rapport : ce qui a bougé dans le modèle, et les vérifications qui réagissent. Si le changement est voulu, enregistrez-le comme nouvelle référence : node outils/verifier-tout.js --enregistrer

Les boucles

Une boucle qui renforce pousse dans le même sens jusqu’à une limite ; une boucle qui équilibre ramène vers un niveau. Chaque flèche dit si elle fait monter (↑) ou baisser (↓) la suivante, et « l’an prochain » quand l’effet arrive un an plus tard.

Tous les réglages

Chaque nombre de data.js, sa valeur actuelle, ce qu’il touche, et ce qui bouge quand on l’augmente de 10 % — mesuré sur le parcours du cours, en année 3 (salle pleine).

Ajouter un mécanisme

Pour qui modifie app.js. Une année se calcule toujours dans cet ordre ; chaque étape se trouve en cherchant le nom de sa fonction.

  1. Les décisions s’appliquent à la clinique — applyAction.
  2. Les heures disponibles : contrats, absences, formations, réservations — initialResources.
  3. La demande de chaque service : foyers, prix, confiance, marché, horaires — projectedDemand, acceptedPrice.
  4. Chaque service : ce que les heures permettent, la part de salle, les ruptures de stock, les demandes perdues par cause — simulateYear (boucle des services, champ lostBy).
  5. Les salles et équipements : utilisation, saturation — simulateYear (facilityRows).
  6. L’argent : recettes, coûts, impôt, prime, trésorerie — simulateYear (partie financière).
  7. Les relations : confiance, climat, pression, référents, démissions — simulateYear (trustParts, climateParts).
  8. Les foyers de l’an prochain — simulateYear (clientGrowth).
  9. Les promesses — commitmentsFor, goalChecks, loanRate.
  10. Les écrans et les exports lisent le rapport de l’année ; ils ne calculent rien.

La règle pour ajouter un effet

  1. Prendre un instantané : node outils/verifier-tout.js --enregistrer.
  2. Ajouter le nombre dans un bloc de data.js, avec un commentaire, à une valeur neutre (0, ou 1 pour un multiplicateur).
  3. L’utiliser dans app.js. verifier-tout doit dire « aucune différence » : le mécanisme est branché sans rien changer.
  4. Mettre la vraie valeur, relancer, lire ce qui a bougé.
  5. Déclarer la flèche dans outils/carte/variables.js ; la carte refuse de se construire tant qu’un nombre de data.js n’y est rattaché à aucune flèche.

Les mots utilisés

Fait monter, fait baisser
Quand une variable augmente, elle fait monter ou baisser celle qu’elle touche.
L’année suivante
L’effet n’arrive pas tout de suite, mais un an plus tard.
Stock
Une quantité qui se garde d’une année à l’autre : foyers, confiance, climat, trésorerie.
Flux
Ce qui se compte sur une année : demandes, cas, coûts.
Réglage
Un nombre de data.js, ou une décision des joueurs.
Prévision et résultat
Avant de passer l’année, le jeu montre une prévision ; les causes (contrainte principale, refus par cause) ne sont données qu’au résultat.
Instantané
Les chiffres de quinze parcours fixes, année par année : en le comparant avant et après un changement, on voit exactement ce qui a bougé.
Effet en chaîne
Une mesure faite en poussant une autre variable : elle montre toute la chaîne, pas seulement cette flèche.
